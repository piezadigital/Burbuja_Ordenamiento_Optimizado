# Tarea de Estructura de Datos - Apoyo con IA

## Objetivo
Optimizar el algoritmo de ordenamiento de burbuja utilizando un índice de posición del último intercambio, con el lenguaje de programación Java.

## Prompts (Instrucciones) enviados a la IA:
Me encuentro estudiando "algoritmos de búsqueda y ordenamiento", concretamente el algoritmo de "Burbuja" clásico. Ahora puedes explicarme como seria la mejora u optimización del algoritmo de burbuja en el cual se pueda implementar un marcador o índice de posición para que este no recorra o pase verificando nuevamente en las posiciones donde ya esta ordenado el array. Muéstrame la explicación y ejemplo para desarrollarlo en java.
